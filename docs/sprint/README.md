# Sprint Capability History

> **Status: historical as a group.** This tree mixes two populations, and
> `docs/DOC_STATUS.md` is the authority for which is which:
>
> - **Active sprint documents** are listed individually under *Sprint Knowledge
>   Base* in `docs/DOC_STATUS.md`; the index is `sprint-working-index.md`.
> - **Everything else here is history**: closed-out sprints, batch audits, and
>   superseded capability plans.
>
> A concrete row in the status map always wins over this group's default.

Read the history portion only when investigating that area, checking why a
decision was made, or doing regression archaeology. For current capability state,
read the code, focused tests, and the active sprint rows first.

No files were moved to create this landing page; the tree keeps its original
paths so existing references stay valid.
