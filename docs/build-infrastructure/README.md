# Build Infrastructure History

> **Status: historical.** This tree is a delivery and audit record. It is not
> current architecture authority, not a validation source, and not part of the
> default read set. See `docs/DOC_STATUS.md` for the status of this group.

Read these documents only when investigating that area, checking why a decision
was made, or doing regression archaeology. For current behavior, read the code
and focused tests; for current architecture, read `docs/architecture/` and
`docs/ACTIVE_CONTEXT.md` first.

## What is here

- `*-planning-summary.md` and `*-audit-summary.md`: BI/MTB batch closeouts.
- `browser-*.md`: browser integration route history.
- `agent-*.md`: agent capability and loop-connection route history.
- `mtb*.md`: model/tool batch handoff route history.

No files were moved to create this landing page; the tree keeps its original
paths so existing references stay valid.
