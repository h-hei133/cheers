## 入口与验证边界

- CLI 根：`packages/ts-shell/src/entrypoints/*`。
- 纳入边：静态 `from`、相对动态 `import()`；本轮未发现指向本仓文件的 worker/globalThis/createRequire 加载。

- 删除前后必须重新运行同一 BFS，要求所有保留文件继续可达；再运行 `npm run build:ts`、全量 vitest 与 golden gate。
