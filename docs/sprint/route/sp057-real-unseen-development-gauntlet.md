Force real autonomous development ability through unseen disposable development tasks.

This goal is failed unless normal runtime plus execution seam completes real unseen tasks with actual edits, targeted verification, repair, artifact or continuation evidence, changed-file accounting, task proof, and result verdict.

For every capability brought in, evaluate in order:

1. dependency use
2. structured port

## Required Tasks

Create or update:

docs/sprint/real-unseen-development-gauntlet.md

Design 5 to 7 unseen disposable development tasks. They must not recycle SP044 through SP056 tasks.

Required coverage:

- at least 3 tasks require multi-file edits
- at least 2 tasks require failed verification, repair, and targeted rerun
- at least 1 task requires artifact claim-source-verification proof
- at least 1 task requires continuation or compact or replay carry-forward
- at least 1 task requires missing-context discovery before edit
- at least 5 tasks exercise normal runtime plus execution seam
- at least 3 tasks include actual write evidence and post-write verification

Each task must record expected changed files, verification target, failure or repair trigger, proof requirement, and exact not-proven condition.

## Required Process

Run the tasks before product fixes.

For each task, record:

- initial outcome
- weak phase
- runtime path
- execution seam behavior
- changed files
- verification target and result
- repair attempt and result
- artifact or continuation state
- missing proof
- owner gap
- product fix

If a task fails for product-runtime reasons, fix rightful owners and rerun the same task.

A failed task is allowed only if it remains explicitly not-proven with exact missing proof and is not counted as complete.
