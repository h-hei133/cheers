# Local Reference Repositories Analysis

## Summary of Reference Projects

1. **`pi` & `pi-docs-playbook`**:
   - Streamlined, event-driven agent loop.
   - Decoupled tool pipeline and state persistence.
2. **`opencode`**:
   - Multi-provider model adapters with streaming token and tool-call normalization.
   - Interactive terminal UI patterns.
3. **`GitNexus`**:
   - Codebase knowledge graph and symbol-level call graph indexing.
   - High-precision contextual dependency slicing.
4. **`mini-swe-agent`**:
   - Lightweight, deterministic SWE-bench execution loop and rapid exit verification.
5. **`stagehand`**:
   - Playwright-based browser observation, DOM snapshotting, and intent execution.
6. **`mem0` / `graphiti` / `mempalace`**:
   - Tiered memory architectures (working memory, episodic memory, entity knowledge graphs).
7. **`inspect_ai`**:
   - Evaluation harness for AI capabilities and sandbox safety.
