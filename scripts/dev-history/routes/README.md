# Route History Runners

This directory contains historical route runner and benchmark scripts moved
during Reset Route H.

Compatibility rules:

- Existing `verify:route*` package commands remain supported.
- New `verify:route-history:*` package commands call the same moved scripts.
- Route221 anti-false-success gate assets are not here because they remain
  active evidence infrastructure.
- Report output paths under `docs/implementation-context/` are intentionally
  preserved so Route221/227/228 compatibility checks keep their provenance.
